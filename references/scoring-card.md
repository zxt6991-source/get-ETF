# 评分卡：权重、分档与字段口径

用于把第 2～5 步的定性/定量信息压缩成一个可比较的综合分。**分数只是排序工具，不是结论本身**，所有分档都必须在报告里回指原始数据。

## 一、五维度权重

| 维度 | 权重 | 对应步骤 | 回答 |
| --- | --- | --- | --- |
| 可交易性 `liquidity` | 10% | 第 1 步 | 买得进卖得出吗？会清盘吗？ |
| 编制质量 `design` | 15% | 第 2 步 | 规则是否稳健、是否分散？ |
| 集中度 `concentration` | 20% | 第 3 步 | 风险是否押注在少数个股/板块？ |
| 历史表现 `performance` | 30% | 第 4 步 | 赚钱能力、抗跌能力、策略有效性？ |
| 价值 `valuation` | 25% | 第 5 步 | 现在买贵不贵、未来增速与股息？ |

**缺失维度自动归一化**：只填了 3 个维度时，权重按剩余维度的相对比例重新分配，报告会同时输出「数据覆盖率」，覆盖率 < 60% 时结论只作参考。

## 二、分档规则（脚本内置，与此表一致）

### 1. 可交易性
| 指标 | 分档 |
| --- | --- |
| 规模（亿元） | ≥50→100 分；≥20→85；≥5→70；≥2→55；≥1→40；<1→直接淘汰 |
| 近 20 日平均成交额（亿元） | ≥5→100；≥2→90；≥0.5→75；≥0.2→60；≥0.05→40；<0.05→20 |

子权重：规模 0.6 / 成交额 0.4。

### 2. 编制质量
| 指标 | 分档 |
| --- | --- |
| 成分股数量 | ≥200→100；≥100→90；≥50→75；≥30→60；≥20→45；<20→35 |
| 单股权重上限 | ≤5%→100；≤10%→85；≤15%→65；≤20%→50；无上限/更高→30 |
| 调仓频率 | 月度/季度→100；半年度→85；年度→60；不调仓或其他→50 |

三项等权平均。

### 3. 集中度（越低越好）
| 指标 | 分档（阈值→分） |
| --- | --- |
| 前十大权重占比 | ≤25%→100；≤35%→85；≤45%→70；≤55%→55；≤70%→40；≤80%→30；>80%→15 |
| 第一大行业权重（二级） | ≤30%→100；≤40%→85；≤50%→70；≤60%→55；≤75%→40；>75%→25 |

子权重：前十大 0.6 / 第一大行业 0.4。

### 4. 历史表现
- **收益子项（权重 0.40）**：1 年、3 年年化、5 年年化的分档取平均（有几年算几年）
  - 1 年：≥60%→100；≥35%→90；≥20%→70；≥10%→50；≥0→30；<0→10
  - 3/5 年年化：≥40%→100；≥25%→90；≥15%→70；≥8%→50；≥0→30；<0→10
- **风险子项（权重 0.35）**
  - 最大回撤：≤20%→100；≤30%→80；≤40%→60；≤50%→40；≤70%→20；>70%→5
  - 年化波动率：≤15%→100；≤20%→85；≤25%→70；≤30%→55；≤40%→40；>40%→20
- **信息比率子项（权重 0.25）**：≥1.0→100；≥0.7→85；≥0.5→70；≥0.3→50；>0→35；≤0→20

### 5. 价值
- **估值子项（权重 0.40）**：PE 分位与 PB 分位取平均，越低越好
  - ≤20%→100；≤40%→85；≤60%→65；≤80%→45；>80%→25
- **盈利增长子项（权重 0.35）**：未来两年净利润增速预测
  - ≥50%→100；≥30%→90；≥20%→75；≥10%→55；≥0→40；<0→25
- **股息率子项（权重 0.25）**：≥5%→100；≥4%→85；≥3%→70；≥2%→60；≥1%→45；<1%→30

## 三、画像标签（脚本自动打）

| 标签 | 触发条件 |
| --- | --- |
| 分散均衡 | 前十大 ≤45% 且第一大行业 ≤45% |
| 集中高弹性 | 前十大 ≥60% 或第一大行业 ≥60% |
| 龙头主导 | 第一大个股权重 ≥ 15% |
| 低估值成长 | PE 分位 ≤30% 且盈利增速 ≥15% |
| 高股息防御 | 股息率 ≥4% 或（股息率 ≥3% 且波动率 ≤20%） |
| 流动性与清盘风险 | 规模 <5 亿或成交额 <0.2 亿 |
| 估值偏高 | PE 或 PB 分位 >80% |

## 四、CSV 字段清单（`scripts/etf_screen.py` 输入）

| 字段 | 含义 | 单位 | 示例 |
| --- | --- | --- | --- |
| `code` | ETF 代码（或指数代码） | — | 510630 |
| `name` | 名称 | — | 消费ETF |
| `track_index` | 跟踪指数名称 | — | 上证消费指数 |
| `scale_yi` | 规模 | 亿元 | 12.5 |
| `avg_amount_yi` | 近 20 日平均成交额 | 亿元 | 0.85 |
| `constituents` | 成分股数量 | 只 | 30 |
| `weight_cap_pct` | 单股权重上限 | % | 15 |
| `rebalance` | 调仓频率 | 文本 | 半年度 |
| `top10_pct` | 前十大权重占比 | % | 75.78 |
| `top1_pct` | 第一大个股权重 | % | 15.7 |
| `sector_top1_pct` | 第一大二级行业权重 | % | 87.45 |
| `sector_top1_name` | 第一大二级行业名称 | 文本 | 食品饮料 |
| `sector_top2_pct` | 第二大二级行业权重 | % | 5.2 |
| `ret_1y_pct` / `ret_3y_ann_pct` / `ret_5y_ann_pct` | 1 年收益 / 3 年年化 / 5 年年化 | % | 28.4 |
| `max_dd_pct` | 历史最大回撤（绝对值填正数） | % | 42.6 |
| `vol_ann_pct` | 年化波动率 | % | 26.3 |
| `info_ratio` | 信息比率 | — | 0.62 |
| `pe_pctile` / `pb_pctile` | PE/PB 历史分位 | % | 35 |
| `earnings_growth_pct` | 未来两年净利润增速预测 | % | 18 |
| `dividend_yield_pct` | 股息率 | % | 3.1 |
| `fee_pct` | 管理费+托管费 | % | 0.60 |
| `launch_date` | 上市日期 | YYYY-MM-DD | 2013-02-06 |
| `as_of` | 数据截止日 | YYYY-MM-DD | 2026-06-30 |
| `source` | 数据来源 | 文本 | 基金季报/中证指数官网 |

留空 = 未知，写成 `-` / `NA` / `待补` 也会被识别为未知，不会当 0 处理。
