## 输出形式建议

- 对话内报告：用上面的结构精简为表格 + 结论，控制在可读长度。
- 落地文件：写入工作区 `reports/[赛道]-etf-挑选-[YYYYMMDD].md` 并 `show_artifact`。
- 飞书：需要文档用 `lark-doc`，需要表格/多维表格用 `lark-sheets` / `lark-base`（表头参照本文第二～七节的列）。

## HTML 富交互版（推荐用于交付/分享）

上文九节结构可**一对一映射**成 HTML 报告。**直接复制现成实例改数据**，不要从零设计：

- 实例：`examples/消费ETF挑选报告-20260919.html`（消费 ETF，44 只候选 → 7 只代表品种 → 7 个跟踪指数）
- 规范：`references/html-report-guide.md`（页面骨架、设计 token、5 张图表规格、卡片文案公式、生成顺序）

映射关系与 HTML 版的增量要求：

| 本文各节 | HTML 版对应 | 增量 |
| --- | --- | --- |
| （页头） | `h1` + `.sub` | 必须写数据截止日、分析范围口径、候选 N → 入选 M → 覆盖 K 个指数 |
| （新增） | KPI 四卡 | 候选总数 / 入选数 / 赛道估值水位 / 赛道近 1 年表现 |
| 一、结论先行 | `.rec` 决策卡片 ×3～5 | 标题用「要 X → 标的（代码）」；**必须写代价**（波动/回撤/规模/溢价） |
| 七、综合评分 | 表1 + 横向条形图 | 综合分轴要做最小值截断，否则分差看不出 |
| 二、候选池 | 表2 | 末列「是否代表品种」说明入选或剔除原因 |
| 三、编制信息 | 表3 | — |
| 四、行业穿透 | 表4 + 集中度分组柱 | 缺数据的指数在图上填 `null` 留缺口 |
| 五、历史表现 | 表5 + 收益柱 + 风险收益散点 | 收益柱按正负染色；散点"右下角"= 高收益低回撤（含基准对比点） |
| 六、价值分析 | 表6 + 估值分位·股息双轴图 | 盈利增速缺失时明确写"待补"并说明价值维度如何重归一化 |
| 八、风险与预警 | 编号条目 ×5～7 | 点名到具体标的与字段，并说明"排名含金量是否打折" |
| 九、数据来源 | 表7 + `.disc` + `.foot` | 页脚写报告生成时间与分析方法链条 |

注意：实例通过 CDN 加载 ECharts，**离线打开无图**。用 `create_document` 产出对话内 HTML 时必须移除外部脚本（改内联 SVG / CSS 条形图或降级为表格）；需要落盘分享则在本地内联 `echarts.min.js`。
