# 数据源、口径与校验

原则：**先权威一手，再第三方补齐；每个数字都要能指回来源与日期。**

## 一、按数据类别找来源

| 数据类别 | 首选来源 | 备选 / 补充 |
| --- | --- | --- |
| 指数编制方案（选样、加权、调仓、权重上限） | 中证指数公司 csindex.com.cn、国证指数 cnindex.com.cn、上交所/深交所指数官网的《指数编制方案》PDF | 基金公司官网的指数介绍页、ETF 招募说明书 |
| 指数成分股与权重 | 指数公司官网月度/季度成分股文件（Excel/CSV）、指数单页 | 基金公司 ETF 页面持仓明细、第三方行情站指数页面 |
| 基金规模、份额 | 基金季报/年报、基金公司官网产品页、交易所基金公告 | 天天基金等第三方（注意其"规模"口径与季报差异） |
| 成交额、流动性 | 交易所行情数据（近 20 交易日均值） | 第三方行情站历史成交 |
| 费率 | 基金合同、产品资料概要、基金公司官网 | 第三方基金页面 |
| 跟踪误差 | 基金季报/年报披露 | 自算：基金净值收益率 vs 指数收益率 |
| 估值分位（PE/PB） | 指数公司官网指数估值、中证指数估值文件 | 第三方估值工具（务必核对起始年份与口径） |
| 盈利预测 | 券商研报一致预期（Wind/Choice 等终端） | 公开研报摘要（需注意覆盖率与偏差） |
| 股息率 | 指数公司官网指数单页（有股息率字段的指数） | 第三方估值工具 |

## 二、可编程获取（可选，非必需）

方法论文档里的表 5-3 类数据（消费 ETF 的四个跟踪指数对比）属于典型的"手工整理 + 交叉核对"型表格。若需要批量获取，可用：

- **AKShare**（开源，免费）：覆盖基金与指数数据。它的文档更新频繁，**接口名以当前版本为准**；AKShare 自带离线的接口注册表，可在本地按关键词检索接口，例如：

  ```python
  import akshare as ak
  # 按关键词模糊查找接口（不联网）
  print([k for k in ak.__dict__ if "etf" in k])
  # 或使用内置注册表
  print([x for x in ak.interface_registry() if "etf" in x.lower()])  # 以实际版本 API 为准
  ```

  常见的用法方向：① ETF 实时行情表（按名称筛选候选池、取规模与成交额）；② ETF 历史净值（算收益/回撤/波动/信息比率）；③ 指数估值数据（取 PE/PB 历史序列算分位）。
- **Tushare / Wind / Choice / iFinD**：需要账号与积分，指数估值与一致预期数据更全。
- 本 skill 的 `scripts/etf_screen.py` **不依赖任何第三方库**，只做"拿到数据后的打分"，因此离线可用。抓数环节可由 agent 用 web_fetch/browser 或上述 SDK 单独完成，产出 CSV 后交给脚本。

## 三、口径纪律（最容易出错的地方）

1. **规模口径**：季报"期末净资产"vs 第三方"最新规模"可能差一整个季度；报告里写清用的是哪个。
2. **成交额口径**：用近 20 个交易日均值，不要用单日（尤其不要用异动日）。
3. **收益率口径**：区分"累计收益"与"年化收益"；3 年以上必须年化并标注计算方法（几何平均）。
4. **回撤口径**：注明区间（近 3 年 / 成立以来）与频率（日频/周频），周频回撤一般比日频偏小。
5. **估值分位口径**：注明起始年份与指标（PE-TTM / 静态 PE / 等权 or 市值加权），并提醒成分股调整造成的失真。
6. **基金 vs 指数**：跟踪误差、费率是"基金"属性，编制信息、成分权重是"指数"属性，逐列不要混。
7. **多份额**：同一 ETF 的场内份额与联接基金（A/C）规模不可直接相加比较费率。

## 四、交叉校验清单（输出前逐条过）

- [ ] 规模：基金公司/交易所披露 vs 第三方是否一致？不一致时取权威并注明。
- [ ] 跟踪指数名称：基金合同中的指数全称是否与第三方简称对应？
- [ ] 前十大权重合计是否 ≈ 100% 减去其余权重（明显偏离说明取错了表）。
- [ ] 行业权重合计是否 ≈ 100%（可能因多行业归类而略偏离）。
- [ ] 收益/回撤/波动是否来自同一区间？跨区间比较必须重算。
- [ ] 所有未知字段是否显式标为"待补"，而不是被 0 或空值静默替代？
- [ ] 报告是否包含数据截止日、来源、免责声明？

## 五、合规提醒

- 输出为公开数据的整理与分析，**不构成投资建议**；不承诺收益、不预测点位。
- 不抓取需要付费或违反站点条款的数据；不绕过登录与反爬。
- 涉及个人持仓、账户信息时不要写入报告文件。
